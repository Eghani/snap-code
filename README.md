# Snapcode

Snapcode is a minimal, browser-based QR code generator. Paste any `http://` or `https://` link and download the result as a PNG, JPG,
or SVG file.

## Use it

Open `index.html` in a browser. No build step or installation is required.

The QR renderer is loaded from jsDelivr, so an internet connection is needed
when the page first loads.

## Features

- Generate QR codes from any valid web link
- Download PNG, JPG, and SVG versions
- Responsive, minimal interface with no account required

## Project files

- `index.html` — page structure and QR code controls
- `style.css` — responsive minimal theme
- `script.js` — validation, QR generation, cursor effect, and downloads
